## 📌 项目概述与核心痛点解决

本平台围绕**普通买家、种植合作社、产地主播、采购批发商、平台运营管理、农技质检专家**六类核心角色，深度解决现代农业流通的三大核心矛盾：
1. **销路分散与产销脱节**：打通源头直发与 B2B 大宗对接，实现“以需定产”、“产地直发”；
2. **产地货源真实性难核验**：“好产品，不烧心”——每件农货绑定地理经纬度、田间实拍、320项农残零检出与专家质检证书，提供数字化一物一码追溯；
3. **农民与合作社使用门槛高**：专为移动智能机设计“极简手机端两步极速上架”与“自主库存调控（防滞销）”。

## 💻 六大核心角色功能亮点

1. **🛒 普通买家 (FelixBuyer 卡通头像)**：
   - 仿淘宝双列流体货架浏览、产地直发与百亿补贴标识、0 延迟多维检索；
   - **独立购物车中心**：多选勾选、件数与金额实时核算、包邮与售后保障提示、吸底统一结算；
   - 沉浸式直播带货体验：点击商品抢购时，直播自动缩小为右下角画中画悬浮窗，边听边买；
   - 一物一码防伪真实溯源查询（播种、灌溉、采摘、质检、顺丰冷链全流程时间轴）；
   - 极速下单结算、订单跟踪与生鲜磕碰坏果“极速退款”维权通道。
2. **👨‍🌾 种植合作社 (UncleFarm 卡通头像)**：
   - 手机端快速上架当季农产品（产地、预估产量、上市周期、阶梯供货价）；
   - 上传田间实拍与农残检测报告，发起“田间预售”、“产地直供”；
   - 自主管理库存，自由划拨大宗配额与零售配额，防止丰产滞销；
   - 在线审阅采购商大宗询价单，支持接受报价或还价磋商，实时查看资金回款。
3. **🎥 产地主播 (SunnyAnchor 卡通头像)**：
   - 绑定源头合作社直供货源，一键挂载到直播间（1号、2号链接）；
   - 直播中点击“设为正在讲解商品”，所有在线观众端同步悬浮展示产地档案与质检报告；
   - 观众端彩色爱心向上飘升粒子动效与公屏实时弹幕互动；
   - 直播复盘看板：实时统计在线人次、带货订单数、GMV 与转化率。
4. **🏢 采购批发商 (ManagerZhang 卡通头像)**：
   - 按品类、产地、上市时间筛选大宗货源（吨级起订量）；
   - 在线发起大宗询价（录入吨数、期望单价、最晚交期与冷链包装要求）；
   - 达成意向后，系统自动组装法律条款生成加盖时间戳的《大宗电子意向订单合同》；
   - 支持在线预约实地看货考察。
5. **🛡️ 平台运营管理 (SuperAdmin 卡通头像)**：
   - 合作社商户营业资质审查；
   - 违规宣传农产品强制下架与封禁，直播间违规切断；
   - 全国产销大数据决策看板（实时交易总额、全国销售地域热力排行、品类分布报表）；
   - 交易纠纷在线仲裁处理。
6. **🔬 农技质检专家 (QualityExpert 卡通头像)**：
   - 负责 37 款地标农品源头实地抽检与 320 项农残专项筛查；
   - 签发“好产品，不烧心”权威绿标与官方品质认证报告；
   - 实时监控顺丰温控冷链温度与采收批次质量。

## 🚀 极速本地运行与演示指南

### 1. 后端服务启动 (`backend`)
- **环境要求**：JDK 21 LTS, Maven 3.8+
- 系统默认内置了 H2 内存数据库与初始数据，**无需提前安装和配置外部 MySQL / Redis 即可一键直接启动**！
```bash
cd backend
mvn spring-boot:run
```
- 启动成功后，后端 API 接口运行在：`http://localhost:8080/api`
- 内置数据控制台：`http://localhost:8080/h2-console`

*(若切换至本地正式 MySQL，只需在 `backend/src/main/resources/application.yml` 中取消 MySQL 驱动注释并导入 `sql/schema.sql` 即可。)*

### 2. 前端服务启动 (`frontend`)
- **环境要求**：Node.js 18+ / 20+ / 22+
```bash
cd frontend
npm install
npm run dev
```
- 浏览器访问：`http://localhost:3000` 即可看到仿淘宝全套视觉界面与五角色自适应工作台！
- 页面顶部提供**五类角色一键切换开关**，点击即可随意切换角色身份并体验对应工作台。
