## 1. 引言

### 1.1 编写目的
本可行性研究报告旨在对“基于 SpringBoot+Vue 的‘不烧心’农产品直播电商产销对接平台（标语：好产品，不烧心）”进行全面、系统的技术、经济、操作、社会与法律可行性论证与评价，明确项目建设的必要性与可行性，分析项目面临的风险并给出应对策略，为软件工程后续的需求分析、系统设计和工程实施提供科学可靠的决策依据。

### 1.2 项目背景
我国是农业生产与消费大国，但长期以来农产品流通体系存在以下突出矛盾：
1. **产销信息不对称与销路分散**：分散的小农户与种植合作社缺乏全国性大市场对接渠道，丰产不丰收、“菜贵伤民，菜贱伤农”现象频发；
2. **中间流通环节冗长**：传统供应链经多级批发商层层加价并伴随高损耗率，农户利润薄弱，消费者与批发商采购成本高昂；
3. **真实性与溯源难核验**：市面农产品良莠不齐，假冒地理标志、虚标产地现象屡禁不绝，采购商和普通消费者买到劣质产品“烧心又费钱”；
4. **数字农贸基础薄弱**：种植端农户不熟悉复杂的电脑软件，急需极简手机端快速上架与直采撮合工具。

为此，依托现代移动互联网、直播流媒体以及成熟的 Web 开发技术，借鉴主流成熟电商（如淘宝）的高级交互与展示形态，创立“**不烧心**”农品直供品牌，确立“**好产品，不烧心**”的品牌主张，开发一套专为**普通买家、种植合作社、产地主播、采购批发商、平台运营管理、农技质检专家**六类核心主体服务的综合性产销对接电商平台，具有强烈的现实迫切性与广阔的市场前景。

### 1.3 术语与品牌定义
- **“不烧心”品牌**：寓意消费者买得放心、吃得安心、合作社卖得顺心、渠道商批发舒心，真正杜绝以次充好带来的“心堵心烦”；
- **好产品，不烧心**：全平台品控准则，以田间地头实景直播、一物一码真实溯源、320项农残零检出与合作社源头直发为基石；
- **卡通视觉体系**：全平台各类用户默认配置现代化 DiceBear 矢量卡通头像，生动亲切，强化乡村电商亲和力；
- **产销对接**：生产基地/种植合作社与批发商或终端消费者直接建立商贸交易，跳过传统多层级中间渠道；
- **预售/直供**：在农作物尚未完全采收或集中上市前，发布预订方案，实现“以需定产”、“产地直发”；
- **产地档案**：包含地理环境、土壤水质、种植日志、田间实拍及农残检测报告的一体化数字化信用凭证；
- **统一购物车**：提供仿淘宝独立 Cart View，支持商品勾选、多店铺合并结算、数量调节与优惠满减；
- **B2B大宗询价**：批发商按吨/批次发起定制化价格沟通与交付排期协商的非标撮合机制。

## 2. 项目建设目标与范围

### 2.1 建设目标
1. **构建五位一体的服务闭环**：打通合作社（生产端）、主播（营销端）、批发商（大宗流通端）、消费者（零售端）与平台管理员（监管端）。
2. **复刻高可用电商交互体验**：参考淘宝双列瀑布流、头部综合检索、沉浸式直播挂车购、订单追踪和即时消息提醒。
3. **实现全链路溯源真实性**：每批次农副产品关联经纬度产地、检测报告、田间实拍图片/视频，解决信任痛点。
4. **支持灵活的交易双模**：既支持普通消费者“C端一键零售秒杀”，又支持采购批发商“B端大宗在线询价与意向合同签约”。

### 2.2 业务范围
- **平台端**：PC端管理中心与大屏监控；
- **移动端与客户端**：支持响应式手机端操作（合作社手机极速上架、消费者移动端逛播下单）以及 PC 端大宗操作平台。

## 3. 技术可行性分析 (Technical Feasibility)

### 3.1 核心技术栈评估
本项目采用当前工业界成熟、稳定、生态繁荣且轻量高效的微服务级轻量化技术栈：

| 层次 | 选用技术 / 框架 | 选型依据与优势 |
| :--- | :--- | :--- |
| **前端展现层** | Vue 3 + Vite + Element Plus + Pinia | 响应式双向绑定、组合式 API (Composition API) 逻辑复用度高；组件库丰富，渲染性能极高，适配多端自适应布局；支持仿淘宝 UI 的高还原度定制。 |
| **后端服务层** | Spring Boot 3.x + Java 21 LTS | 企业级成熟规范，依赖注入、RESTful 风格开箱即用；Java 21 虚拟线程支持高并发网络 I/O；Spring Security + JWT 提供成熟的无状态多角色鉴权。 |
| **数据持久层** | MySQL 8.0 + MyBatis-Plus | 关系型强事务保障订单与财务数据一致性；ACID 特性确保资金交易安全；MyBatis-Plus 减少 CRUD 冗余代码并提供分页插件。 |
| **缓存与消息** | Redis 7.x | 热点商品秒杀库存扣减、高频商品缓存、用户会话令牌及分布式锁，抵御高并发流量。 |
| **实时通讯** | WebSocket (STOMP 协议) | 实现直播间弹幕实时滚动、主播挂载商品动态推送到客户端、大宗订单状态实时消息触达。 |

### 3.2 难点与解决措施
1. **大文件（田间视频/质检报告大图）上传流畅度**：
   - *措施*：采用前端分片断点续传、图片异步压缩算法（WebP格式转换），配合对象存储服务（OSS/MinIO），有效降低服务器网络带宽负载。
2. **高并发直播带货库存防超卖**：
   - *措施*：采用 Redis Lua 脚本预扣减库存 + 数据库乐观锁（版本号机制）进行最终一致性结算，避免库存负数与并发脏读。
3. **资金与交易数据安全**：
   - *措施*：密码使用 BCrypt 加密算法，敏感通信采用 HTTPS 加密传输，涉及大宗合同订单使用摘要签名算法校验防篡改。

### 3.3 技术可行性结论
团队成员具备扎实的 Java、Vue 和数据库基础，选用组件均属于主流成熟开源技术，配套技术文档与开源社区支持充足，技术风险极低，**技术方案完全可行**。

## 4. 经济可行性分析 (Economic Feasibility)

### 4.1 成本估算 (Cost Breakdown)
作为高校课程设计与产学研孵化原型项目，项目成本主要分为硬件基础设施与软硬件环境：
- **开发与部署硬件成本**：开发阶段依托个人电脑，云服务器部署阶段采用轻量级云主机（2核4G，费用约 50~100元/月），支持云上演示；
- **软件许可成本**：全技术栈均采用 Apache 2.0 / MIT 开源协议（OpenJDK、MySQL Community、Redis、Vue、VS Code / IntelliJ IDEA Community），**基础软件采购费用为 0 元**；
- **人力成本**：小组学生协同开发，课程设计阶段不计入商业工资支出，主要投入为学习与研发工时（约 120 人天）。

### 4.2 预期经济与社会效益
1. **种植合作社端**：缩减传统流通环节加价率 20%~35%，实现产地直供的高利润率，通过预售机制减少滞销损耗 40% 以上；
2. **采购商与消费者端**：大宗批发价公开透明，消费者以低于传统商超 15%~25% 的价格买到正宗产地原生态农货；
3. **平台盈利模式（商业化预期）**：
   - 大宗交易撮合技术服务费（0.5%~1%）；
   - 产地认证与名特优新农产品推荐展位费；
   - 供应链金融与产地冷链仓储对接信息增值服务。

### 4.3 投资回报分析
项目研发投入极小，边际成本接近于零，具备显著的经济合理性与投入产出比优势。**经济可行性良好**。

## 5. 操作与社会可行性分析 (Operational & Social Feasibility)

### 5.1 操作可行性 (Operability)
1. **界面交互友好度**：仿淘宝现代电商设计语言，主流用户具备成熟的网购习惯，无需额外培训即可上手；
2. **合作社低门槛设计**：专门针对农村合作社人员设计“极简手机端发布模式”，拍照即识别、两步完成发布、大字体大图标呈现，极大降低操作学习壁垒；
3. **管理员一站式中台**：提供可视化数据图表与快捷审核流，降低日常运维复杂度。

### 5.2 社会与法律可行性 (Social & Legal Feasibility)
1. **政策导向**：符合国家“乡村振兴”、“数字乡村”、“互联网+现代农业”战略方向，受地方农业农村局及产业政策政策大力扶持；
2. **法律合规性**：严格遵守《中华人民共和国电子商务法》、《中华人民共和国网络安全法》、《个人信息保护法》及《中华人民共和国食品安全法》；
3. **版权与资质**：系统所有图片、视频和文字素材均通过合作社实名签署授权，不存在知识产权侵权风险。
