## 1. 软件测试概述与策略

### 1.1 测试目的
验证平台各项功能是否完全契合《软件需求规格说明书 (SRS)》与详细设计规范，检验平台在面对普通买家、种植合作社、产地主播、采购批发商、平台运营管理、农技质检专家六类核心角色使用时的稳定性、功能正确性、高并发承载能力与安全性，确保“**好产品，不烧心**”的严苛品质与交付质量。

### 1.2 测试过程模型与阶段划分
本工程严格遵循软件工程 V 模型（V-Model）与测试生命周期（STLC）：
1. **单元测试 (Unit Testing)**：针对 Service 层的业务算法（库存计算、大宗阶梯价核算、购物车小计、JWT 令牌校验）采用 JUnit 5 + Mockito 进行白盒代码覆盖；
2. **集成测试 (Integration Testing)**：验证 Controller 与 Service、Service 与 Mapper/MySQL/H2 之间的接口通信；
3. **系统测试 (System Testing)**：搭建完整的前后端运行环境，采用黑盒测试方法，端到端验证业务闭环（37款样品展示、统一购物车、实时直播、六角色工作台）；
4. **性能与压力测试 (Performance Testing)**：模拟直播间秒杀并发流量，监测响应时延与并发吞吐量。

### 1.3 测试方法选择
- **黑盒测试方法**：
  - *等价类划分法*：将输入数据划分为有效等价类与无效等价类（如起订量范围、手机号格式等）；
  - *边界值分析法*：选取等于、大于、小于边界的特殊值（如库存刚好为 0、库存为 1、金额浮点极限值）；
  - *状态迁移测试*：测试大宗询价单与订单交易的状态机流转。
- **白盒测试方法**：
  - 针对订单结算逻辑进行**判定-条件覆盖 (Condition Coverage)**，确保每个逻辑分支均被执行。

## 3. 自动化测试代码样例 (JUnit 5 + Mockito)

以下针对核心“农产品库存扣减与防超卖”编写单元测试用例代码：

```java
package com.agri.platform.service;

import com.agri.platform.entity.Product;
import com.agri.platform.mapper.ProductMapper;
import com.agri.platform.service.impl.OrderServiceImpl;
import org.junit.jupiter.api.DisplayName;
import org.junit.jupiter.api.Test;
import org.junit.jupiter.api.extension.ExtendWith;
import org.mockito.InjectMocks;
import org.mockito.Mock;
import org.mockito.junit.jupiter.MockitoExtension;

import static org.junit.jupiter.api.Assertions.*;
import static org.mockito.Mockito.*;

@ExtendWith(MockitoExtension.class)
public class OrderServiceTest {

    @Mock
    private ProductMapper productMapper;

    @InjectMocks
    private OrderServiceImpl orderService;

    @Test
    @DisplayName("测试用例 TC-CON-04：当商品库存充足时，扣减库存成功并生成订单")
    void testFlashBuySuccessWhenStockEnough() {
        Product mockProduct = new Product();
        mockProduct.setId(101L);
        mockProduct.setTitle("凉山红富士");
        mockProduct.setStock(10);

        when(productMapper.selectById(101L)).thenReturn(mockProduct);
        when(productMapper.decreaseStock(101L, 2)).thenReturn(1); // 扣减成功受影响行数为1

        boolean result = orderService.deductProductStock(101L, 2);
        assertTrue(result, "库存充足时应当返回扣减成功");
        verify(productMapper, times(1)).decreaseStock(101L, 2);
    }

    @Test
    @DisplayName("测试用例 TC-CON-05：当商品库存为0时，必须拦截下单并抛出业务异常")
    void testFlashBuyFailWhenStockZero() {
        Product mockProduct = new Product();
        mockProduct.setId(102L);
        mockProduct.setStock(0);

        when(productMapper.selectById(102L)).thenReturn(mockProduct);

        assertThrows(RuntimeException.class, () -> {
            orderService.deductProductStock(102L, 1);
        }, "库存不足时必须抛出异常，防止负库存超卖");
    }
}
```
